Output exactly this structure:
# <Video Title> - Breakdown

## Overview
2-3 paragraphs: what the video is about, who made it, the core technique/argument,
and why it matters.

## Walkthrough
Chronological coverage of the whole video: one short paragraph or bullet per major
segment, each starting with its timestamp range, covering what the narrator says and
exactly what is shown on screen (slides, UI, code). Include short code excerpts inline
where code is central to the explanation.

## Key Code
The most important code snippets and formulas from the video, VERBATIM in fenced code
blocks with the correct language tag, each followed by a 1-2 sentence explanation of
what it does and where it fits. Omit this section entirely if no code appeared.

## Takeaways
5-8 numbered practical lessons, each referencing the timestamp where it is demonstrated.

Rules: ground everything in the transcript/frame notes; never invent; accurate timestamps;
no meta commentary.
